# Changelog

## 1.0 — first public release

TapForge 1.0 is the first public/FOSS release.

- Phone-side NDEF Type 4 HCE and direct NFC receive mode.
- Physical NDEF tag reading, writing, cloning, erase/format/read-only workflows.
- NDEF Studio and reusable Profile Library.
- Batch Write with duplicate UID protection and optional read-back verification.
- Compare Tags, Compatibility Check and SHA-256 NDEF fingerprints.
- APDU Lab for user-supplied ISO-DEP commands.
- Undo Last Write for restoring the previous readable NDEF to the same tag UID.
- URL, text, email, phone, SMS, location, contact/vCard, Wi-Fi/WPS, Android app, MIME, external type and raw NDEF records.
- Local NFC history.
- Adaptive OLED/light/system UI, reduced-motion mode, optional haptics and clean opaque navigation.
- English, Spanish, Portuguese, French, German, Italian, Japanese, Simplified Chinese, Korean and Russian UI resources.
- No Internet permission, analytics, ads or account requirement.
- GPL-3.0-or-later source release.
