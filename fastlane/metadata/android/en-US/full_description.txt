TapForge is a local-first, open-source NFC toolkit for Android.

Use your phone as an NDEF Type 4 HCE device, receive NFC content, read and write physical NDEF tags, build multi-record messages in NDEF Studio, keep reusable profiles, batch-write tags with verification, compare tags, run compatibility checks and inspect ISO-DEP/APDU exchanges.

TapForge supports common NDEF content such as URLs, text, email, phone, SMS, location, contacts/vCard, Wi-Fi/WPS, Android application records, MIME, external types and raw NDEF.

Privacy is simple: TapForge has no Internet permission, no ads, no analytics and no account. Optional contact permission is requested only when importing a contact.

TapForge clones readable NDEF content only. It is not a payment-card, transit-card or protected access-credential cloning tool.
